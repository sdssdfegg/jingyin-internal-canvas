# Codex 提问模板

以后要改 V11，可以按这个格式发给 Codex。

## 通用模板

```text
项目：D:\静音AI绘画V11（源码）

我要改：
（一句话说明功能，例如：批量换脸默认提示词 / 快捷生成上传区 UI / 保存目录 / 出图并发）

涉及板块：
（快捷生成 / 批量生成 / 参考生图 / 一键详情 / 图片编辑 / 视频 / 设置 / 发布包）

相关维护文档：
V11维护文档\00-总索引.md
V11维护文档\01-目录分区与维护地图.md
（如涉及重复 UI，加：V11维护文档\02-重复功能同步登记表.md）
（如涉及提示词/SKILL，加：prompts\README.md）

当前问题：
（现象、报错、哪里不符合预期）

希望效果：
（改完后你希望看到什么）

验收方式：
（打开哪个页面，做什么操作，看到什么结果）
```

```text

（批量换装 / 批量姿态 / 固定背景 / 随机背景 / 扩图 / 改色 / 白底 / 换脸 / 设计稿 / 局部回贴）

改前问题：
（比如：图2下装被带入、脸变了、袖口不稳定）

新规则：
（你想新增/删除/改写的规则）

影响范围：
只改前端默认提示词 / 只改后端 SKILL / 两边都要同步检查

必须不变：
（比如：UI 不变、并发不变、接口不变、其他工作流不变）

验收：
（打开哪个页面，默认词是否变化，生成时最终规则是否变化）
```
