## 当前代码入口

目前所有批量 workflow 的实际 JSX、状态、任务构建仍在：

```text
src/outfit-workflow.jsx
src/outfit-workflow.css
```

不要一次性把它全部拆空。以后每次只迁一个 workflow，迁完运行检查和构建。

## 共用能力不要复制

| 能力 | 统一位置 |
| --- | --- |
| 批量生成 API | `src/api/outfit.js` |
| API 请求底座 | `src/api/client.js` |
| 用户 KEY | `src/features/auth/api-key.js` |
| 后端提示词出口 | `prompts/server/outfit-skill.js`（2026-09-26 起 = 只发用户原话，SKILL/规则已删除） |
| 模型和尺寸 | `src/shared/models.js` |
| 局部蒙版 | `src/shared/local-edit-mask.js` |
| 上传区/结果卡/设置弹窗 | 后续进 `src/shared/ui/` |

## 修改某个分区时怎么发给 Codex

示例：只改随机背景。

```text
V11维护文档/00-总索引.md
V11维护文档/05-批量分区功能地图.md
src/features/outfit/workflows/random-background/README.md
prompts/README.md
```

如果涉及 API，再加：

```text
V11维护文档/04-API调用与登录系统地图.md
src/api/outfit.js
```

如果涉及重复 UI，再加：

```text
V11维护文档/02-重复功能同步登记表.md
src/shared/ui/README.md
```

## 当前重点问题定位

| 问题 | 优先发送文件 |
| --- | --- |
| 批量白底精修色差、牛仔提蓝、图钉/夹子/衣架、褶皱整理 | `src/features/outfit/workflows/white-refine/README.md`、`src/outfit-workflow.jsx`（`WHITE_REFINE_DEFAULT_PROMPT`） |
| 随机背景偏暖、亮度不统一、人物硬抠边贴图感 | `src/features/outfit/workflows/random-background/README.md`、`src/outfit-workflow.jsx`（`RANDOM_BACKGROUND_DEFAULT_PROMPT`） |

> 2026-09-26 起后端不再追加任何 SKILL / 规则（只发用户原话），上面两类问题只能通过默认提示词或用户自己写的提示词解决。

只改这类问题时，不需要把整个项目或全部历史大文件发过来；先发对应 workflow 的 README、维护地图和相关提示词/API 文件即可。
