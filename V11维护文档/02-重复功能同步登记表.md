# V11 重复功能同步登记表

这张表用于避免“改了一个地方，另一个分区还是旧逻辑/旧 UI”。

规则：只要一个能力暂时还没有抽到 `src/shared/`、`src/shared/ui/`、`server/shared/` 或 `prompts/`，但它在多个功能里重复存在，就必须登记在这里。

## 新增功能时怎么登记

如果你发现自己要复制一段已有 UI 或逻辑：

1. 先判断能不能直接抽到 shared。
2. 如果这次不方便抽，就在本表新增一行。
3. 写清楚 A/B 位置和同步检查点。
4. 下次改其中一个位置时，先搜这张表。

## 修改前检查口令

每次准备改 UI 或功能时，先问：

```text
这个东西是否在两个以上地方出现？
如果是，它有没有进入 shared？
如果没有，它有没有登记在 V11重复功能同步登记表？
```

三个问题任意一个答不上来，就先不要动大文件。
