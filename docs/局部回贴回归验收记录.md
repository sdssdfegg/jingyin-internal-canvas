## 4. 贴回诊断字段记录

批量局部回贴结果会在 `result.localEdit.diagnostics` 内保留贴回合成参数，并在结果预览面板显示一行诊断摘要。测试时如果某张图失败，优先记录这些字段：

| 字段 | 用途 |
| --- | --- |
| `strategy` | 当前贴回策略，例如 GPT 局部贴回或 Banana 局部贴回 |
| `pasteRect` | 最终贴回原图的位置和尺寸 |
| `contextRect` | 给模型看的上下文区域 |
| `frameFit` | 生成局部图映射到上下文框的方式；GPT 当前使用 `stretch` 强坐标填充 |
| `autoAlign` / `align` | 是否启用自动对齐、实际偏移 dx/dy、边缘采样得分 |
| `colorMatch` / `colorMatchDetail` | 是否启用色彩匹配、采样数量、RGB 调整幅度、边缘淡出范围；重点看 `preventLightening`、`lighteningLimited`、`lumaLift` 是否说明程序拦截了变浅 |
| `skinProtect` | GPT 局部贴回是否启用上方肤色/脸部保护、保护像素数量和模糊半径 |
| `sharpen` | GPT 局部贴片是否执行轻微清晰度补偿；如果为 `too-large`，说明贴片像素过大，为避免卡顿跳过 |
| `output` | 最终贴回成片的导出格式、是否 PNG 无损、字节数和目标上限，用于判断是否因为整图 JPEG 二次压缩导致全图变糊 |
| `feather` | 最终羽化像素 |
| `hasMask` | 是否使用涂抹蒙版 |
| `taskBinding` | 当前结果绑定的任务、图1名称、局部裁剪文件、上传文件、批量模式、贴回坐标、裁剪 Q 和裁剪字节数；用于排查批量里图和局部区域是否串位、裁剪图是否被过度压缩 |

## 5. 回归判定

一轮回归至少要覆盖：

- 1 张包含脸部边缘的局部回贴。
- 1 张包含袖口/衣摆边缘的局部回贴。
- 1 张包含腿部或肤色边缘的局部回贴。
- 1 张关闭局部回贴的普通 GPT 批量换装对照图。
- 1 张图1普通手动裁剪后走裁剪生成回流的批量换装对照图。

通过标准：

- 局部回贴整体通过率不低于 80%。
- 不出现明显降分的脸部糊化。
- 不出现整张成片明显变软、发糊或压缩感；未修改区域的脸、发丝、背景纹理和服装肌理应接近原图清晰度。
- 结果预览诊断中应能看到裁剪 Q、输出 PNG 无损和清晰补偿状态，便于定位是否仍存在二次压缩。
- 不出现图2未选中服装部位大面积带入。
- 抬手或弯曲手臂图中，图2长袖袖口落点不漂成九分袖。
- 同批服装亮度、颜色和面料光泽保持一致，不随机提亮、变浅、泛白、降饱和、发灰或改色。
- 不出现浅黄色、米黄色、浅粉色等服装被肤色保护误擦导致的横向半截换装。
- 用户明确要求删除发圈、头饰、配饰、道具、文字、水印时，目标必须完整删除，不只删一半或留下残影。
- 裁剪生成回流测试中，结果预览应能看到原图尺寸、裁剪框尺寸、生成尺寸、完整大图尺寸和输出 Q；保存图尺寸等于图1原图完整尺寸，生成内容落在原裁剪框位置。
- 普通 GPT 批量换装对照图不变差。
