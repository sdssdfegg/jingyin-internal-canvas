# 批量换装一致性 A/B 验收记录

适用目录：`D:\RJ\静音AI绘画V5（源码）`

更新时间：2026-08-13

本文用于记录批量换装一致性优化的测试结果，重点验证同一张图2服装母版在多张图1模特上的版型、细节和穿法是否稳定。

## 1. 测试目标

- 图1人物姿势、脸、发型、身体比例、场景和光影保持稳定。
- 图2服装类别、版型、袖口、袖克夫、袖长、松量、衣长、裤长或裙长保持一致。
- 图2穿法保持一致：衣摆扎法、卷袖状态、扣子扣合数量、拉链高度、腰带系法、领口打开程度不随机漂移。
- 图1原服装不参与图2服装判断：不能因为图1原袖长、松量、衣长或颜色影响图2服装结果。
- 图2服装颜色深浅保持一致：不能被 GPT 变浅、泛白、降饱和、发灰、提亮或改色。
- 图3默认不介入，只有提示词明确点名时才作为弱补充。
- 非局部批量换装原有姿势稳定链路不被破坏。

## 5. 常见失败类型

| 失败类型 | 判定标准 | 严重级别 |
| --- | --- | --- |
| 袖克夫漂移 | 图2袖克夫长短、宽度或收口方式在结果间不一致 | 高 |
| 袖长漂移 | 长袖变九分袖、袖口从腕骨漂到手掌或前臂 | 高 |
| 卷袖漂移 | 图2卷袖结果变放下，或卷袖高度/层数随机变化 | 高 |
| 扣子漂移 | 图2扣几颗，结果随机全扣、全开、多扣或少扣 | 高 |
| 衣摆扎法漂移 | 图2扎入下装，结果变外穿、半扎或露出边界错误 | 高 |
| 版型松量漂移 | 宽松款变正装修身、腰身被模型审美收细 | 高 |
| 箱型廓形漂移 | 短款箱型、落肩、宽松袖筒、横向下摆宽度被改成合体收腰、正肩、袖筒变直的小夹克 | 高 |
| 衣长/裤长/裙长漂移 | 图2长度比例在不同模特上明显不一致 | 高 |
| 图1原服装污染 | 结果跟随图1原衣服的袖长、袖口、松量、衣长、颜色、面料或穿法，而不是图2 | 高 |
| 颜色变浅 | 图2原始服装颜色被提亮、泛白、降饱和、发灰或变成浅一号 | 高 |
| 细节简化 | 扣子、拉链、口袋、拼接线、面料纹理被删减或重设计 | 中 |
| 脸部糊化 | 脸部轻微糊、肤色不自然、五官质感低于图1 | 中 |

## 6. 通过标准

- P0 功能不崩：快捷生成、批量生成、局部回贴入口正常。
- 每组至少 3 张图1模特测试，整体平均分不低于 14/16。
- 高严重级别失败不能连续出现；同一图2母版不允许出现两种不同穿法。
- 开启母版版型锁定后，袖口、袖克夫、卷袖、扣子、衣摆扎法至少有 80% 结果达到 `2` 分。
- 如果不开启母版版型锁定，也不能比优化前更差。
