# 发布包记录

适用目录：`D:\RJ\静音AI绘画V8（源码）`

本文记录每次 Windows 发布包的输出目录、校验值和发布前确认项。以后对外发包时，以本文作为交付查询记录。

## 1. 当前发布规则

- 默认发布目录：`D:\RJ\静音AI绘画-WIN（V9）`。
- 默认启动文件：`D:\RJ\静音AI绘画-WIN（V9）\静音AI绘画.exe`。
- 发布命令：`D:\RJ\node\npm.cmd run release:win`。
- 发布脚本：`scripts/secure-win-release.mjs`。
- 发布包只保留前端内置的默认提示词、批量页面预设、模型列表和公开发布模式需要的静态资源。
- 发布包不携带 `.env`、API Key、`data`、`logs`、上传图、历史图、生图记录和本机运行日志。
- 客户端默认只请求静音中转站 `https://api.jingyin.online/v1`；备用上游由中转站后台自动兜底，客户端不展示 code28/备用渠道和不同价格。
- 公共发布模式会使用 `VITE_JINGYIN_PUBLIC_RELEASE=1` 和 `VITE_JINGYIN_STORAGE_PREFIX=jingyin-public-secure`，首次启动时清理旧的本地历史缓存。
- 当前脚本只生成 EXE；如果后续增加 ZIP，再在记录表中补充 ZIP 路径和 SHA256。

## 2. 发布前检查

```powershell
D:\RJ\node\npm.cmd run check
D:\RJ\node\npm.cmd run build
D:\RJ\node\npm.cmd run build:assets
node --check server\static-assets.generated.js
node --check scripts\secure-win-release.mjs
D:\RJ\node\npm.cmd run release:win
git diff --check
```

发布后人工确认：

- 双击 `静音AI绘画.exe` 能启动。
- 浏览器能打开 `http://127.0.0.1:8787`。
- `/api/config` 返回正常。
- 前端默认进入批量生成工作区。
- 默认提示词和批量页面预设存在。
- 不出现本机历史、生图记录、旧上传图或旧 KEY。
