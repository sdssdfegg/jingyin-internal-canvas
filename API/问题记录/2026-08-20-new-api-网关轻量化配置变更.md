# 2026-08-20 New API 网关轻量化配置变更

## 2026-08-21 重要更正

本记录里的“定时测试所有通道：开启”已经撤销。

原因：

- New API 对图片/视频渠道做通道测试时，可能不是零成本心跳，而是真实调用生成接口。
- 之前把全通道定时测试设为 `10` 分钟，会导致图片渠道周期性真实生成并扣费。

当前确认状态：

- 定时测试所有通道：关闭
- 自动测试所有通道间隔时间：`10` 分钟，但总开关关闭，因此不会触发
- 保存后已刷新回读，仍为关闭

后续规则：

- 生产环境禁止开启全通道定时测试。
- 图片/视频渠道只做手动单渠道测试，测试前必须确认可能真实扣费。
- 自动监控应改用 `/health`、余额查询、模型列表等轻量接口，不能调用真实生成接口。

## 变更边界

- 变更对象：`https://api.jingyin.online/console/setting`
- 变更时间：2026-08-20 晚间
- 变更范围：New API 后台配置
- 未变更范围：未修改画板源码，未修改上游密钥，未新增/删除渠道，未清理日志，未生成/删除令牌。

## 变更目标

让中转站更接近“轻量控制面”：

- 中转站负责鉴权、路由、价格、日志、错误归因。
- 上传大请求尽量降低内存压力。
- 结果图片下载尽量不经过中转站。
- 坏渠道自动退出，恢复后自动回来。

## 已保存的配置

### 1. 运营设置 / 监控设置

历史保存，已于 2026-08-21 撤销：

- 定时测试所有通道：已从开启改为关闭
- 自动测试所有通道间隔时间：`10` 分钟
- 测试所有渠道的最长响应时间：`30` 秒
- 失败时自动禁用通道：开启
- 成功时自动启用通道：开启

保持未改：

- 自动禁用状态码：`401`
- 自动重试状态码：保持后台原配置
- 自动禁用关键词：保持后台原配置

目的：

- 自动禁用/自动启用用于坏渠道退出和恢复。
- 但不能再通过全通道定时测试触发，因为图片渠道测试可能真实生成并扣费。

注意：

- 自动禁用会影响线上路由。后续如果发现某个渠道被误禁用，可以先到渠道管理里查看响应时间和错误原因。
- 图片/视频渠道不允许开启全通道定时测试。

### 2. 绘图设置

已保存：

- 关闭：开启之后将上游地址替换为服务器地址

目的：

- 尽量避免结果图片下载经过 `api.jingyin.online`。
- 中转站只保留任务状态、价格、日志、结果 URL 等轻量数据。

注意：

- 如果某些上游返回的图片 URL 客户端不可访问，画板可能需要改为对象存储/CDN转存方案。
- 如果出现“任务成功但图片打不开”，优先检查结果 URL 是否公网可访问。

### 3. 性能设置

已保存：

- 启用磁盘缓存：开启
- 磁盘缓存阈值：`10 MB`
- 磁盘缓存最大总量：`1024 MB`
- 缓存目录：留空，使用系统临时目录

读回状态：

- 缓存目录：`/tmp/new-api-body-cache`
- 当前缓存：`0 Bytes / 1 GB`
- 可用空间：约 `21.58 GB`

目的：

- 图生图、多图参考等大请求体临时落磁盘，减少内存压力。

## 仍需后续处理

这些不是 New API 后台直接能完成的配置：

- 网关 gzip/brotli 压缩：建议在 Nginx/CDN 层做。
- 上传图片压缩：建议画板本地做。
- 下载图片分片：建议由对象存储/CDN/上游直链支持 HTTP Range。
- 渠道拆分：后续按文本、图片、视频分别配置优先级和权重。
- 控制台图表报错：需要 New API 前端源码或升级版本修复。
