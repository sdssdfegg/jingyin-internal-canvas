- 新渠道 `weight = 100`

- 渠道 JSON 字段检查无非法 JSON。

- 已备份数据库：
  - `/opt/new-api/data/one-api.db.bak-20260826-211621-before-7lai-abilities`
- 已给渠道 ID `8` 补充能力表：

```text
default / nano-banana-2   / channel_id=8 / enabled=1 / priority=60 / weight=60
default / nano-banana-pro / channel_id=8 / enabled=1 / priority=60 / weight=60
default / nano-banana2    / channel_id=8 / enabled=1 / priority=60 / weight=60
```

- 已重启 New API：

结论：

- 问题不是渠道被删了，而是直接写 `channels` 表时没有同步写 `abilities` 表。
- 以后新增渠道尽量走后台页面或 New API 自带接口；如果必须直接改数据库，必须同步维护 `channels` 和 `abilities` 两张表。
