# 渠道能力表 - 2026-08-25

> 只记录协议和能力，不记录密钥、私有 IP、手机号。

| 渠道 | 协议类型 | 适合模型 | 文生图 | 图生图/多图 | 2K 参数 | 是否异步 | 当前定位 |
|---|---|---|---|---|---|---|---|
| 老夜 | OpenAI 兼容图片接口 + 扩展参数 | `gpt-image`, `gpt-image-2`, `nano-banana-pro`, `nano-banana2` | 支持 `/v1/images/generations` | 支持 `/v1/images/edits`，多图字段重复 `image` | `image_size=2K` + `aspect_ratio`，也兼容部分 `size` | 否，图片接口表现为同步等待 | GPT 图片当前主渠道 |
| LK888 GPT | 异步媒体任务 | `tt-image-2`, `tt-image-2-token` | 支持 `media/generate` | 支持 `params.images` | `params.size=精确像素`，如 `1920x2560` | 是，需要 `task_id` 轮询 | 需要适配器后才能做主渠道 |
| 7LAI | JSON 图片生成接口 | 以后台模型 ID 为准 | 支持 `/v1/images/generations` | 参考图走 `image_urls`，不是 multipart `image` | `image_size=2K` + `aspect_ratio` | 截图未显示任务轮询，待验证返回格式 | 需要适配器后参与图片/香蕉 |

## 老夜参数规则

文生图 JSON：

```json
{
  "model": "gpt-image-2",
  "prompt": "...",
  "image_size": "2K",
  "aspect_ratio": "3:4",
  "n": 1
}
```

图生图 multipart：

```text
model=gpt-image-2
prompt=...
image_size=2K
aspect_ratio=3:4
image=@reference_1.jpg
image=@reference_2.jpg
```

注意：

- 文件字段用 `image` 重复传。
- 不用 `image[]`。
- 不把 URL 填到 `image` 文件字段。

## LK888 参数规则

创建任务：

```json
{
  "model": "tt-image-2",
  "prompt": "...",
  "params": {
    "size": "1920x2560",
    "quality": "auto",
    "images": []
  }
}
```

轮询任务：

```text
GET /v1/media/status?task_id=...
```

注意：

- 不能只传 `2K`。
- 普通 `tt-image-2` 可能降采样。
- `tt-image-2-token` 更适合稳定高清，但必须走异步适配。

## 7LAI 参数规则

文生图 / 带 URL 参考图：

```json
{
  "prompt": "...",
  "model": "后台模型ID",
  "aspect_ratio": "16:9",
  "image_size": "2K",
  "n": 1,
  "image_urls": []
}
```

注意：

- 7LAI 图片参考走 `image_urls`。
- 如果画板传的是文件，适配器要先转成可访问 URL 或 Data URI。
- 当前截图没有确认返回结果字段，需要后续用非生图接口或受控测试确认。

## 不能再混用的点

- LK888 不能直接当 `/v1/images/edits` OpenAI 图片接口。
- 7LAI 不能直接吃 OpenAI `multipart image` 文件上传。
- 只做模型名重定向，不等于完成协议适配。
- New API 后台的“透传请求体”只能缓解参数丢失，不能解决接口协议不同。

## 推荐主路由

| 业务 | 主渠道 | 备用 | 说明 |
|---|---|---|---|
| GPT 文本 | 老夜文本 | 其他 OpenAI 兼容文本 | 文本协议清晰 |
| GPT 图片 1K/2K | 老夜 GPT 图片 | LK888 适配器完成后加入 | 先保证 `image_size/aspect_ratio` 不丢 |
| 稳定 GPT 2K | 老夜或 LK888 官转适配器 | 其他高清渠道 | LK888 普通模型不保证精准 2K |
| 香蕉文生图 | 老夜或 7LAI 适配器 | 其他香蕉渠道 | 7LAI 需确认模型 ID 和返回格式 |
| 香蕉图生图 | 老夜优先 | 7LAI 适配器完成后加入 | multipart 与 image_urls 不能直接混用 |
| 视频 | 独立任务适配器 | 不参与图片路由 | 必须任务化 |
