# 静音 API 中转站记录区

这个目录只记录 `https://api.jingyin.online/` 中转站相关的问题、排查结论和代码模板。

边界说明：

- 不修改画板源码。
- 画板始终只对接一个中转站地址：`https://api.jingyin.online/`。
- 上游 API 的兼容、切换、报错归因、故障记录，都应该放在中转站侧处理。
- 这里的代码文件是“中转站源码化/二开时的参考模板”，不是当前画板的运行代码。

文件结构：

- `问题记录/`：每次 API 故障或线上 BUG 的单独记录。
- `API问题索引.md`：所有问题的汇总索引，方便下次按现象检索。
- `API问题记录模板.md`：以后新增问题时复制这个格式。
- `代码模板/`：上游 API 拆分、优先级切换、错误归一化的参考代码。
